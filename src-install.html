Install the app

The handbook installs like a normal app on your phone or PC, with its own icon, and works fully offline after the first open. Pick your device.

Android This device

  1. Open this page in Chrome.
  2. Tap ⋮ → Install app (or Add to Home screen).
or download the APK
Download Android app (.apk)

Open the downloaded file and allow “Install unknown apps” for your browser when Android asks.

iPhone / iPad This device

  1. Open this page in Safari.
  2. Tap the Share button (square with arrow).
  3. Choose Add to Home Screen → Add.

It then opens full-screen from its own icon and works offline. Apple only allows other app installs through the App Store.

Windows This device

  1. Open this page in Edge or Chrome.
  2. Click the Install icon at the right end of the address bar.
or download the installer
Download Windows installer (.exe) Portable version (no install)

If Windows SmartScreen shows “Windows protected your PC”, click More info → Run anyway (the installer is not code-signed).
